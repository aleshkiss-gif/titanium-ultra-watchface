# TITANIUM ULTRA
Original Wear OS digital watch face prototype with black titanium styling, orange arc, time, seconds, and date.

## Build on your phone
1. Open the GitHub **Actions** tab.
2. Select **Build Wear OS APK** and tap **Run workflow** (a push may also trigger it).
3. When the workflow succeeds, download the **TitaniumUltra-debug-apk** artifact and unzip it.
4. The APK is for the **watch**, not the phone. Install it via wireless ADB from your phone using a compatible ADB installer, after enabling Developer options and Wireless debugging on the watch.
5. Select TITANIUM ULTRA in the watch-face chooser.

This is a first source-code prototype. Build and actual watch compatibility are not yet verified. Some recent Wear OS versions may restrict legacy AndroidX watch-face formats.
